- Ma'lumotlar bazasi: **PostgreSQL**, **SQLite**, **SQLAlchemy**
- Frontend: **React + Vite**
- AI agentlar: **LangChain**, **Gemini 2.5 Flash** yordamida agent loyihalar (masalan: MailPulse, PriceWatch, DocAnalyzer)
- Qiziqishlarim: computer vision, ML/AI engineering, game development
